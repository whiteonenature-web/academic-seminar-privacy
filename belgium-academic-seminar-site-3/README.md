# Belgium Academic Seminar — GitHub Pages

A one-page English information site for the academic seminar:

**To What Extent Is Freedom of Religious Expression Guaranteed?**  
*A Comparative Constitutional Study of the South Korea and Belgium Constitutions*

## Files

- `index.html` — Seminar Information + Registration + Privacy Notice
- `styles.css` — Responsive visual design
- `assets/seminar-poster.png` — Seminar poster
- `assets/favicon.svg` — Site icon

## Before publishing

1. Replace `YOUR_META_LEAD_FORM_URL` if you want a button linking to an external registration URL.
2. Confirm that the actual data flow, retention period, recipients/processors, and international transfers match the Privacy Notice.

## GitHub Pages

Create a repository, upload the files to the repository root, then go to:

`Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save`

GitHub Pages will use `index.html` as the entry file.
